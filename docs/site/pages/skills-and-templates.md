# Skills and templates

A project's skills tell its workers how to do a job that comes back. A skill can declare a wish template, which turns
a recurring request, babysitting a pull request or a QA run, into a wish that already knows how to work, and a source
of the inbox. A project can summon another project's skill, without a copy.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
