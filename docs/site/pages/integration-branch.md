# Integration branch

Under the per-wish push strategy, a wish's finished work lands in its integration branch: in each project, the branch
your checkout was on when the wish was made. The chip beside the push strategy, at the top of the wish, names it; a
click changes it to another local branch, or to a new one. Djinn keeps it up with the project's main branch, merging
main in, never rebasing.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
