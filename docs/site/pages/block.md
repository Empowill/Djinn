# Block

A block is what the Djinn and the workers write down for one another: a hand-off, a reference, a report. Blocks are
not for you: they wait in the wish's last tab, **For agents**, each folded under its title, written in Markdown and
shown as written, their diagrams drawn. When a report concerns you, it comes as a question that names it.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
