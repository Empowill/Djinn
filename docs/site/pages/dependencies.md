# Dependencies

A task can come after others: it starts only once they are done and their work committed, and its worktree starts
from that work. The tasks of a wish form a graph without cycle: Djinn refuses a link that would close one, and names
it.

Being part of an [azima](#azima) does not make a task wait; only its dependencies do.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
