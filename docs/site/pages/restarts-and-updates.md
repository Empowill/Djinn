# Restarts and updates

Nothing is lost. Stopping Djinn interrupts the workers; the next start resumes each one in the same task, worktree and
session, and the Djinn comes back on its session. When a newer Djinn is installed, a banner offers **Update**: nothing
restarts without that click.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
