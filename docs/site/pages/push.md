# Push

Djinn pushes a wish's branch itself, never forcing, once the project's push checks pass: one CI run per push instead
of one per worker. Each project has its push cadence: **Standard** pushes at an azima's end, or after an hour and three
tasks committed; **On demand** pushes only when you click **Push**.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
