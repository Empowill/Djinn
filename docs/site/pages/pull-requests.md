# Pull and merge requests

When a task opens a pull or merge request, Djinn watches it in the same wish: once the task ends, a watcher starts on
it, and each change it reports, a failed pipeline, a comment, a conflict, wakes the Djinn, until the request is merged.
The project names how to follow one in one of its skills; without one, nothing starts.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
