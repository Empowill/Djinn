# Project and settings

A project is a folder Djinn's workers work in, a Git repository or not. **Create a project**, the **+** next to
Projects in the side panel, adds one. A repository can share defaults for its workers in its team settings: which
agent runs them, which model, how much a task may spend, and the checks Djinn runs on finished work. Your own settings
win over the team's.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
