# Push strategy

Each wish has a push strategy. **Per wish**: one integration branch per wish and project, where all its work lands.
**Per azima**: one branch per azima, cut from main, landing in main through its own pull request. Switch it at the top
of the wish.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
