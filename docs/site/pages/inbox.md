# Inbox

A skill may declare a source: a command that prints what comes from outside, like the merge requests assigned to you.
Each item becomes a card in the **Inbox**, at the top of the flying carpet, with the wish Djinn proposes to send it
to. Nothing is made until you click; Djinn only reads a source, never answers it.

Each source says what it reads, in a sentence its skill writes in its metadata, else the skill's description. Djinn
keeps its last run on this machine: when it ended, how many items it printed, and why it failed, since when; the
Djinn's command line lists the sources with them.

> **This page is a sketch.** Its full guide, how to use it from the window and from the Djinn, what to expect and
> the common mistakes, is being written.
