# Djinn v0.1.0

Djinn is a local desktop application and orchestrator that turns your high-level intents into reality through autonomous coding agents. It provides a native window, a local server, and a command line to guide, supervise, and collaborate with your agents while keeping you in complete control.

## Features

- **The window**: A native desktop application built with Wails that adapts to your system's light or dark appearance. Bring it forward at any time with the global shortcut `Ctrl+Alt+Space`. If WebKitGTK is not installed on Linux, Djinn starts in browser mode with the exact same interface.
- **Wishes and azimas**: Organize your goals into wishes (up to three active at a time). Complex wishes break down into azimas—focused phases of work with clear objectives, dependency tracking, and collapsible progress cards.
- **Questions that wait for you**: When agents face choices or need direction, they post clear multiple-choice questions in the Decision Log. Answer them at your own pace, click **Rub the lamp** to turn recommendations directly into tasks, or choose **Enlighten me** to have an agent investigate before deciding. Desktop notifications alert you whenever a decision awaits your input.
- **Workers on Claude, Codex, or Antigravity**: Assign tasks to worker agents powered by Claude Code, Codex, or Google Antigravity (`agy`). Each worker operates in its own isolated Git worktree, displays live terminal output and token cost tracking, and can be paused, resumed, or guided mid-turn.
- **The orchestrator that integrates and pushes by itself**: Djinn coordinates workers, resolves task dependencies, resumes work after interruptions or quota resets, and runs commit and push checks (`djinn gate`) before integrating completed work into your repository with clean Git hygiene.
- **Tilasms**: Rich visual artifacts—interactive diagrams, data models, Mermaid graphs, and markdown summaries—rendered right inside the window, shareable as single HTML files or linked with `djinn://tilasm/<id>`.
- **The command line**: A comprehensive CLI (`djinn`) to control projects, wishes, tasks, and decisions from your favorite shell or script, complete with integrated documentation and shell autocompletion.
- **Backups**: Safeguard your wishes and history with automated backups and one-file exports (`djinn wish export`), allowing complete restoration across sessions.
- **Updates from inside the app**: Djinn checks for new releases and lets you update the binary in place with one click in the app or via `djinn update`, restarting seamlessly.

## Install

Install Djinn with a single command—no administrator privileges or `sudo` required. The installer downloads the binary for your system, verifies its SHA-256 checksum, and places it in your user folder:

**macOS and Linux:**
```sh
curl -fsSL https://github.com/Empowill/Djinn/releases/latest/download/install.sh | sh
```

**Windows (PowerShell):**
```powershell
irm https://github.com/Empowill/Djinn/releases/latest/download/install.ps1 | iex
```

## Status and Verification

Djinn v0.1.0 is an alpha release.
- **Linux (amd64)**: Verified by hand end-to-end—the native GTK3 window, browser mode, CLI, and file-based installation have been tested on real hardware.
- **macOS & Windows**: Binaries (universal macOS Mach-O, `Djinn.app`, Windows amd64 and arm64 executables) are built and verified by automated continuous integration in GitHub Actions, but have not yet been tested by hand on physical hardware.
- **macOS Gatekeeper**: macOS builds are currently unsigned and not yet notarized. If downloaded via a web browser, macOS may quarantine the application until allowed in *System Settings > Privacy & Security*, or by running `xattr -dr com.apple.quarantine Djinn.app`. The `curl` installation script does not set quarantine attributes.
