# T1 · Compose a wish workspace

**Goal.** A wish opens as a sparse, useful summary and lets the developer compose its task, decision, tilasm,
agent, journal, instruction and rights sections into a resilient workspace.

**Implementation.** Keep the wish header and urgent actions globally available, render each section once, support
drag, keyboard and explicit direction controls for nested splits, persist layouts per wish when storage is available,
and translate the interface in English and French.

## Done when

- [ ] The sparse wish summary, section composition, responsive stack, persistence and deep links work without hidden
      duplicate mounted content.
- [ ] Every move, close, maximize, restore and permission or lifecycle action remains keyboard and screen-reader
      reachable.
- [ ] English and French catalogs cover all workspace text, and owned source files pass formatting and type checks.
